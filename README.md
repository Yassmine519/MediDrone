# MediDrone — Autonomous Medical Delivery Drone + Mobile App

> A Flutter-based companion application for an autonomous medical delivery drone, enabling real-time mission monitoring and control.

---

## Overview

**MediDrone** is a complete medical logistics system consisting of an autonomous delivery drone and a cross-platform mobile application. The app allows healthcare operators to dispatch drones for medical supply delivery, monitor flight status in real-time, and receive delivery confirmations.

Developed as part of the **MEDITECH** engineering challenge.

---

## Features

- **Mission management** — dispatch and track autonomous medical deliveries
- **Real-time drone telemetry** — live position, battery, altitude display
- **Cross-platform** — Android and iOS from a single Flutter codebase
- **Clean UI/UX** — intuitive interface designed for healthcare operators

## Getting Started

### Prerequisites
- Flutter SDK (latest stable)
- Android Studio or VS Code with Flutter extension
- Physical device or emulator

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/MediDrone.git
cd MediDrone/app_mediDrone/mon_app
flutter pub get
flutter run
```
